## Visual intent

- Apple-inspired restraint rather than decorative complexity.
- One application canvas rather than pages nested inside pages.
- Strong typography and spacing hierarchy.
- Fewer visible borders and nested cards.
- Desktop layouts that use the available monitor width.
- Mobile layouts that feel intentionally native to phone dimensions.
- Large board-centric Trainer and Daily workspaces.
- Exact existing Daily concentric rings.
- Existing board semantic colors and instructional overlays remain untouched.
- Transparent Blundr/Tempo assets used sparingly.
- Mascot motion is subtle:
  - gentle float/bob;
  - occasional blink treatment where technically appropriate;
  - no constant distracting motion;
  - `prefers-reduced-motion` disables new decorative motion.

## Important implementation instruction

Do not copy prototype JavaScript, fake state, mock values, or mock navigation into production.

Use the existing production controller/component and reproduce only the target presentation around it.
